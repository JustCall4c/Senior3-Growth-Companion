# 🌱 高三成长陪伴助手

一款为高三学生及家长量身打造的本地化成绩管理与情感陪伴 Web App，无需后端，数据全存本地，开箱即用。

---

## ✨ 功能亮点

### 📊 成绩管理
- **多科目录入**：支持语文、数学、英语、物理、化学、政治六科成绩与排名同步录入
- **总分自动核对**：录入时系统自动将六科加总与手填总分比对，防止笔误
- **排名全覆盖**：支持班排、校排、级排三维度记录
- **历史记录**：随时查看、编辑或删除任意一次考试记录

### 📈 深度分析
- **分科趋势图**：可切换总分或任意单科，查看历次考试的成绩走势（面积图）
- **排名追踪**：班排、校排、级排趋势折线图，双 Y 轴设计，量纲不同也清晰可辨
- **历史极值**：自动标注历史最高分、最低分及平均分
- **雷达图**：最近一次考试的六科满分率可视化一览

### 🏆 荣誉勋章系统
系统依据历史数据自动颁发成就徽章，激励持续进步：

| 勋章 | 触发条件 |
|------|----------|
| 🏅 学科战神 | 某科排名进入年级前 225 名（文科/理科自适应） |
| 🚀 逆风翻盘 | 总分或排名有显著提升（10 分 / 50 名以上） |
| 🐢 稳如泰山 | 某科连续三次排名波动 ≤ 10 名 |

### 🤖 AI 智能复盘
一键生成包含全量历史数据的定制化提示词，可直接粘贴至 Kimi、豆包、文心一言等大模型：

**学生视角**
- 综合分析与冲刺策略
- 指定科目专项突破法
- 考前心态调整与鼓励信

**家长视角**
- 非暴力沟通指导方案
- 成绩估分与志愿填报准备
- 考前家庭后勤与氛围营造

### 💌 树洞日记（双端隔离）
- **妈妈的树洞** / **yx的树洞**：两个相互独立、密码保护的私密日记空间
- 支持新建、编辑、删除日记条目，操作带二次确认防误触
- 支持修改密码，忘记密码可通过开发者重置码找回

### ⏱️ 高考倒计时
实时显示距 2026 年高考（6 月 7 日 9:00）的天/时/分/秒，以及从高三开学至今的奋斗进度条。

### 📦 数据备份与恢复
- 支持单独导出**成绩数据**、**妈妈树洞**、**yx树洞**（树洞需密码验证）
- 智能识别粘贴内容格式，一键恢复任意类型数据

## 🚀 快速开始

该项目为纯静态 HTML，无需任何构建工具或服务器。

```bash
# 直接用浏览器打开
open index.html

# 或使用任意静态服务器（推荐，以支持 PWA）
npx serve .
```

**PWA 支持**：需同目录下放置 `manifest.json` 与 `sw.js` 以支持安装到桌面/主屏幕。

## 💾 数据存储

所有数据保存在浏览器 `localStorage`，**不上传任何服务器**，完全本地隐私。

| Key | 内容 |
|-----|------|
| `grade_app_v4_data` | 所有考试成绩记录（JSON 数组） |
| `grade_app_v4_msg` | 家庭寄语文本 |
| `grade_app_v4_name` | 学生姓名 |
| `grade_app_mom_*` | 妈妈树洞相关（日记、密码、留言） |
| `grade_app_yanxi_*` | yx树洞相关（日记、密码、留言） |

> ⚠️ 清除浏览器缓存会导致数据丢失，请定期使用"备份/恢复"功能导出数据。
